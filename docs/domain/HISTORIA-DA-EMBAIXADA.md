# Memória histórica

A Embaixada deve preservar sua história para futuras gerações.

Registrar marcos com data/período, título, descrição, categoria, pessoas relacionadas, atividade relacionada, fotos/documentos e autoria do registro.

Categorias sugeridas: Fundação, Diretoria, Cerimônia, Acampamento, Competição, Premiação, Projeto, Missões, Aniversário, Outro.

Permitir linha do tempo anual e retrospectiva.
