# Segurança e privacidade

O sistema trata dados de crianças/adolescentes.
- mínimo privilégio;
- isolamento multi-tenant;
- criptografia em trânsito;
- segredos fora do repositório;
- auditoria de alterações sensíveis;
- uploads privados com autorização;
- proteção contra enumeração de usuários;
- rate limiting em autenticação;
- logs sem dados pessoais desnecessários;
- política de retenção e exclusão a definir;
- backup e restauração testados;
- validação de autorização em cada endpoint.
Considerar LGPD no desenho e operação.
