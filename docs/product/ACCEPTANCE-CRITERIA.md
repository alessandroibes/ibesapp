# Critérios de aceite essenciais

- Registrar conclusão de cada requisito/tarefa com data de negócio independente da data de lançamento.
- Não exigir ordem das tarefas.
- Não promover antes de tarefas + permanência mínima.
- Registrar ingresso no próximo posto na mesma data da conclusão oficial.
- Frequência aceita visitante.
- Primeira reunião é derivada.
- Agenda aceita eventos recorrentes, prazos, cancelados e múltiplos dias.
- Evento externo identifica entidade promotora.
- Reunião pode nascer de roteiro/modelo.
- Aptidão é definida por Conselheiro.
- Escalação filtra por aptidão + elegibilidade na data-base.
- Prova coletiva respeita mínimo/máximo/reservas.
- Nenhuma operação vaza dados entre tenants.
