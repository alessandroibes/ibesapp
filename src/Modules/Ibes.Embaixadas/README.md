# Embaixadas

Fase 1: Conselheiro e liderança institucional com histórico. Igreja e Embaixada mantêm a identidade 1:1 definida na fundação.

Entidades neste módulo; persistência em `Ibes.Infrastructure`; casos de uso HTTP em `Ibes.Api/Features/Dominio/EmbaixadaEndpoints.cs`. A API compõe o cadastro de Pessoas e a associação opcional com conta adulta da Igreja. Cargo não concede permissão.
